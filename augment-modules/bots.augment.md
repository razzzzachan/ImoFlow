# bots.augment.md

## Objetivo
Gerar atendimentos automáticos em canais como WhatsApp, site, telefone e capturar dados para o CRM.

## Modo de uso
- Modo Assistido: edição limitada de fluxos
- Modo Avançado: edição completa liberada por plano

## Funcionalidades
- Assistente configurável via IA
- Fluxo com variáveis: nome, imóvel de interesse, urgência, bairro
- Gatilhos: QR code, link, botão no site, mensagem
- APIs integradas: OpenAI (NLP), Whisper (voz), TTS (voz ativa), Clientechat (conector)

## Conexões
