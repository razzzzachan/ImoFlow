# Estrutura do Projeto ImmoFlow

Crie a base do projeto com as seguintes pastas e tecnologias:

## Estrutura de Pastas
/apps/web → Frontend React com Tailwind e Shadcn
/apps/api → Backend Fastify ou tRPC
/modules/auth → Autenticação e permissões
/modules/crm → CRM com pipeline visual
/modules/whatsapp → Atendimento automatizado
/modules/ai → Processamento IA (áudio, imagem, PDF)
/modules/dashboard → Painel gerencial
/modules/integrations → Integrações externas

## Requisitos
- Use Supabase para banco, auth, storage
- Use Fastify ou tRPC no backend
- Frontend com React + Tailwind
- Estrutura modular, organizada e escalável
