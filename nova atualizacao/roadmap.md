# roadmap.md

## Visão Geral
Este roadmap descreve os marcos de desenvolvimento, lançamento e escalabilidade da plataforma ImmoFlow.

## MVP (Fase 1)
- Bot de WhatsApp com captura de leads
- Mini-CRM com histórico e etiquetas
- Painel de tarefas e lembretes automáticos
- Integração básica com Supabase e API REST
- IA de respostas rápidas (FAQ inteligente)

## Fase 2
- Dashboard analítico para corretores
- Assistente de voz para busca e ações rápidas
- App mobile (Flutter ou React Native)
- IA preditiva de fechamento de vendas
- Integração com portais imobiliários (ZAP, OLX)

## Fase 3
- OCR de documentos e contratos
- Geração automática de anúncios
- VoiceBot para ligação ativa
- Sistema de recomendações inteligente
