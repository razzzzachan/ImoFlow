# ImmoFlow

**Status**: ✅ **MVP 100% IMPLEMENTADO E FUNCIONAL** (30/01/2025)

ImmoFlow é uma plataforma SaaS plug-and-play que automatiza o atendimento, vendas e gestão de processos de corretores e imobiliárias usando Inteligência Artificial.

## 🎉 **SISTEMA COMPLETO FUNCIONANDO**
- ✅ **7 interfaces** completas e navegáveis
- ✅ **Estratégia de monetização** implementada (R$ 29 a R$ 1.200)
- ✅ **Dados realistas** para demonstração convincente
- ✅ **URLs ativas**: Frontend (3000) + Backend (3001)

## Tecnologias
- React (Front-end)
- Fastify (Back-end)
- Supabase (Banco de dados e autenticação)
- OpenAI API (IA para bots e automações)

## Funcionalidades Principais
- Bot de atendimento via WhatsApp
- CRM interno para controle de leads
- Painel de agendamentos e rotinas
- API aberta para integrações externas
- Gestão automatizada com IA
